## 📚 Список работ

- **Лабораторная работа №1**: Базовая верстка текста с использованием HTML и CSS.
- **Лабораторная работа №2**: Табличная и блочная резиновая верстка макета.
- **Лабораторная работа №3**: Адаптивная верстка на Flexbox. Основы JS: работа с хэшами и функциями для предметной области «Авиакомпания».
- **Лабораторная работа №4**: ООП в JavaScript. Реализация класса `THashStorage` для хранения и управления данными.
- **Лабораторная работа №5**: Динамическая генерация HTML-форм на основе JS-массива через DOM.
- **Лабораторная работа №6**: Валидация данных формы на JS и построение динамического многоуровневого меню из массива.
- **Лабораторная работа №7**: Создание базовой архитектуры Single Page Application (SPA).
- **Лабораторная работа №8**: Работа с AJAX. Подгрузка HTML-страниц и данных из JSON-файла. Первичное развертывание SPA на сервере Express.
- **Лабораторная работа №9**: Разработка веб-приложения на Express.js. Реализация REST API (CRUD) с хранением данных в JSON-файле и рендерингом через EJS.
- **Лабораторная работа №10**: Разработка WebSocket-чата с использованием Express и Socket.IO.
- **Лабораторная работа №11**: Настройка сборщика Webpack. Перевод клиентской части на реактивное программирование с использованием библиотеки RxJS (потоки, `ajax`, `combineLatest`, `switchMap`).

## 🚀 Как запустить

Для лабораторных работ, требующих Node.js (Лаб 8–11), выполните следующие команды в терминале:

```bash
npm install
npm run build
npm start
```

После запуска сервер будет доступен по адресу `http://localhost:3000` (или другой порт, указанный в `server.js`).

## 📚 List of Works

- **Lab 1**: Basic text layout using HTML and CSS.
- **Lab 2**: Table and block responsive layout of the mockup.
- **Lab 3**: Adaptive layout using Flexbox. JS basics: working with hashes and functions for the "Airline" domain.
- **Lab 4**: OOP in JavaScript. Implementation of the `THashStorage` class for storing and managing data.
- **Lab 5**: Dynamic generation of HTML forms based on a JS array via DOM.
- **Lab 6**: Form data validation in JS and building a dynamic multi-level menu from an array.
- **Lab 7**: Creating a basic Single Page Application (SPA) architecture.
- **Lab 8**: Working with AJAX. Loading HTML pages and data from a JSON file. Initial deployment of the SPA on an Express server.
- **Lab 9**: Developing a web application using Express.js. Implementing a REST API (CRUD) with data stored in a JSON file and rendered via EJS.
- **Lab 10**: Developing a WebSocket chat using Express and Socket.IO.
- **Lab 11**: Setting up the Webpack bundler. Converting the client-side to reactive programming using the RxJS library (streams, `ajax`, `combineLatest`, `switchMap`).

## 🚀 How to Run

For laboratory works requiring Node.js (Labs 8–11), run the following commands in the terminal:

```bash
npm install
npm run build
npm start
```

After starting, the server will be available at `http://localhost:3000` (or another port specified in `server.js`).
